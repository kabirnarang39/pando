How it works

  1. An agent sends the files it changed.Over the CLI, plain git push, an SDK or MCP. No clone of history needed.
  2. The server checks only those paths.If the branch moved but nothing touched your paths, the server rebases for you. If it did, you get the reason and the paths.
  3. The branch moves once per batch.Every queued change lands with one compare-and-swap. A conflicting change fails alone; the rest land.

For agents: a URL and a token

Agents read, search, write and land files over the Model Context Protocol without cloning anything. Each token is scoped to repositories, a role and an expiry, and every action is in the audit log.

claude mcp add --transport http pando https://mcp.example.com/mcp \
  --header "Authorization: Bearer $PANDO_TOKEN"

Claude Desktop, Cursor, ChatGPT, Gemini CLI and other MCP clients take the same URL and header. Inside a workspace, claude mcp add pando -- pando mcp runs the tools locally. Agents and MCP
